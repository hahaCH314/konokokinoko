# このこきのこ

**山を歩くだけのスマホゲーム。すれ違うキノコが、なぜか全員やさしい。**

## どんなゲームか

特に何も起きません。

リアルで神秘的な森の中を、ただ歩きます。敵もタイムリミットもスコアもありません。歩いていると、道の奥から実写のようなキノコが現れて、すれ違いざまに何か言ってきます。

言ってくることは、全部ポジティブです。

> 「今日もよく頑張ったね」
> 「そのままの君でいいんだよ」
> 「マジ好き」

言っているのは、疲れ切った中年男性の顔をしたシイタケだったり、口を全開にして叫んでいるベニテングタケだったりします。**顔が怖いほど、やさしいことを言います。** その落差を楽しむゲームです。

しばらく歩くと森の出口に着きます。どのくらい歩くかは毎回変わります。キノコをひとつも見なくても、ちゃんと森は抜けられます。

## 遊び方

- **画面を押しているあいだ、前に進みます。** 操作はこれだけです
- キノコは**触りません**。この森には猛毒の種類も生えています。見るだけです
- 右上のボタンで昼と夜が切り替わります。夜は地面の菌糸が光ります
- 出口をくぐると終わります

タイトル画面のシイタケの口が入口です。口をタップすると、口の中に吸い込まれて森が始まります。

### キノコのことばについて

`mushroomLines.json` に、変えてはいけない原則を書いてあります。

> **全員ポジティブ。例外を作らない。**
> 顔が怖い個体も、猛毒の個体も、ひとり残らず歩く人を励ます。
> 注意書き・警告・禁止のことばは、どんな理由があっても入れない。
> 「触らないで」ではなく「見ててくれてうれしい」と言わせる。

猛毒のドクツルタケも「君、好きだよ」「ずっと見守ってる」としか言いません。

### 画像の作り方

キノコの元画像は白背景で生成されているため、そのままだと森の中で白い四角になります。次の処理を通しています。

1. 画像の外周から連結している白だけを塗り抜く（単純な白キーだと、白いキノコの傘や柄に穴が空くため）
2. 足元に残る影を落とし、根元を地面に溶かす
3. 複数体が並んだシートから切り出した個体は、隣の破片が混ざるため、本体以外のかたまりを除去する
